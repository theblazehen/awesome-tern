# Contributing

Thanks for helping grow the list.

- Only add things related to [Stencil's Tern](https://stencil.so/tern). Other projects named "tern" (ternjs, etc.) don't belong here.
- Add one item per pull request, in the most fitting section.
- Use the format `- [Name](link) - Description.` Keep descriptions short, factual, and ending in a period.
- Link the repository or canonical post, not a mirror.
- Plugins should be installable with `tern plugin install`, or say clearly how to install them.
- Check that links work and the project isn't abandoned or broken.
